📖 About the Project

NÉHARA is a multi-category luxury marketplace concept focused on combining elegant design, smooth navigation, and a convenient online shopping experience.

The project aims to create a visually appealing and user-friendly platform where customers can explore different product categories in one place.

* Modern and elegant user interface

🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the repository

git clone YOUR_REPOSITORY_URL

2. Navigate to the project folder

cd NEHARA

3. Install dependencies

npm install

4. Start the development server

npm run dev

5. Open in your browser

Visit:

http://localhost:5173

Make sure the development command and port match your project configuration.
