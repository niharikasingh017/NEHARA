🤝 Contributing to NÉHARA

Thank you for your interest in contributing to NÉHARA – A Little Luxury, Every Day.

NÉHARA is a modern, multi-category luxury marketplace project. Contributions, suggestions, bug reports, and improvements are welcome.

🌟 How to Contribute

You can contribute by:

* Reporting bugs and issues.
* Suggesting new features.
* Improving the user interface.
* Enhancing website responsiveness.
* Improving code quality.
* Updating project documentation.
* Fixing existing issues.

🚀 Getting Started

1. Fork the Repository

Fork the NÉHARA repository to your GitHub account.

2. Clone Your Fork

git clone YOUR_FORKED_REPOSITORY_URL

3. Navigate to the Project

cd NEHARA

4. Install Dependencies

npm install

5. Create a New Branch

git checkout -b feature/your-feature-name

6. Make Your Changes

Implement your improvements and test them locally before submitting.

7. Commit Your Changes

git add .
git commit -m "Add: your feature description"

8. Push Your Changes

git push origin feature/your-feature-name

9. Create a Pull Request

Open your fork on GitHub and submit a Pull Request explaining your changes.

📌 Contribution Guidelines

* Keep code clean and readable.
* Follow the existing project structure.
* Use meaningful commit messages.
* Avoid unnecessary dependencies.
* Test your changes before submitting.
* Write clear descriptions for new features.
* Do not commit passwords, API keys, or private credentials.

🐛 Reporting Issues

When reporting an issue, please include:

* A clear issue title.
* Steps to reproduce the problem.
* Expected behavior.
* Actual behavior.
* Screenshots, if applicable.

💡 Feature Suggestions

New ideas and improvements are welcome. Please explain the purpose of the suggested feature and how it could improve the shopping experience.
